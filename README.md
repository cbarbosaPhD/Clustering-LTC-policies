# Clustering-LTC-policies


# R Code for the paper "An ensemble clustering typology of long-term care policies: evidence from 30 OECD countries"

## Overview

This repository contains the R code used for the analyses reported in the following publication in Health Policy.

## Publication

**Title:** An ensemble clustering typology of long-term care policies: evidence from 30 OECD countries

**Authors:** Cristina Barbosa; Nuno de Sousa Pereira

**Journal:** Health Policy

**DOI:** 10.1016/j.healthpol.2026.105795

## Contents

- `scripts/`: R script used for data processing and analysis.
- `README.md`: Documentation for this repository.


## How to use the code

1. Install R and any required packages.
2. Obtain access to the input data described in the article, subject to the relevant data access restrictions.
3. Run the scripts in the order specified in the R file


## Data availability

The data used in this study are publicly available.


## Reproducibility

The code is provided to support transparency and reproducibility of the analyses reported in the publication.
